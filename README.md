# foundedbyMe

An open-source, offline-first 12-week engineering academy to build Noend Node 01, authored by **indigomate**.

## Run locally
Open `index.html` in a browser or serve the folder using `python3 -m http.server 8080`.

## Curriculum and assessments
84 daily lessons across 12 weeks, three task checks and a reflection per day, 21 multiple-choice questions per weekly exam (80% passing), and practical milestone evidence with self-attestation. Passing the exam and submitting the milestone unlocks the next week. This is **not independent verification** of physical skills or safety.

## Data
Progress is stored in browser localStorage. Use **Progress records → Export JSON backup** to save it and import it on another device. No account or server synchronization is implemented. Never enter secrets or private credentials in evidence fields.

## Deploy
Static site. Deploy the repository root with Vercel Framework **Other**, no build command, output directory `.`. GitHub Pages workflow is included.
